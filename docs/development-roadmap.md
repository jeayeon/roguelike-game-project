# 재의 귀환 개발 로드맵

NAN 2026 사전과제 제출까지 남은 작업을 우선순위 순서로 관리합니다.

## 완료

- 웹 개발 환경 및 Phaser 프로젝트 구성
- 이동, 공격, 연속 공격, 대시, 피격, 사망 및 재시작
- 추격자, 중갑 수호자, 원거리 사수 구현
- 상하좌우로 연결된 10개 방과 탐색 미니맵
- 정리한 방 재방문 및 고정 보스방
- 재의 군주 보스 기본 패턴
- 적 밀도 약 1.5배 증가
- 적 월드 경계 충돌 및 방 입장 최소 스폰 거리
- 전투 처치 재화 `재`, 회복방 1개, 상점방 1개
