# 재의 귀환 (Ashes of Return)

브라우저에서 실행되는 2D 탑다운 액션 로그라이트 사전과제입니다.

## 개발 실행

```powershell
npm.cmd install
npm.cmd run dev
```

## 조작

- 이동: `WASD` 또는 방향키
- 공격: 마우스 왼쪽 버튼 또는 `J` (누르고 있으면 연속 공격)
- 대시: `Space`
- 사망 후 `이어서 시작`: `R` 또는 버튼 — 재와 강화를 유지하고 첫 방부터 재시작
- 사망 후 `새 게임 시작`: 버튼 — 재와 강화를 포함한 모든 진행을 초기화하고 첫 방부터 재시작

## 현재 프로토타입

- 플레이어 이동, 마우스 조준, 근접 공격
- 무적 시간이 있는 대시
- 서로 다른 행동을 가진 일반 적 3종: 추격자, 중갑 수호자, 원거리 사수
- 상하좌우로 연결된 10개 방을 자유롭게 탐색하는 던전 구조
- 정리한 방은 재방문 가능하며, 처음 방문하는 방으로 이동할 때 체력 12 회복
- 탐색으로 드러나는 미니맵과 고정된 위치의 보스방
- 3방향 탄막과 높은 체력을 가진 보스 `재의 군주`
- 각 방의 적 수를 이전 버전보다 약 1.5배 증가
- 모든 적에게 방 경계 충돌을 적용하여 원거리 적이 전투 구역 밖으로 이탈하지 않음
- 어느 방향에서 입장해도 적이 플레이어로부터 최소 210px 떨어진 위치에 생성됨
- 처음 정리한 일반 방마다 무작위 강화 3개 중 하나 선택
- 공격·생존·기동 계열 강화 10종과 최대 3~5단계 중첩
- 화면 왼쪽 상단에서 현재 획득한 강화와 레벨 확인
- 적 처치 시 `재` 획득(추격자 3, 원거리 사수 5, 중갑 수호자 6)
- 3번 방의 회복방에서 35% 회복 또는 최대 생명 제물 중 1회 선택
- 7번 방의 상점방에서 구매 카드 3개(회복약 1개·무작위 강화 2개) 중 하나를 선택
- 상점 하단의 별도 버튼 또는 `Esc`/`4`로 거래하지 않고 나가기
- 회복방과 상점방은 사용 후 재방문 시 선택이 반복되지 않음
- 피격, 회복, 사망 및 재도전
- 기본 생명 50으로 시작
- 회복방은 회복하지 않고 나갈 수 있으며, 실제 회복을 사용하기 전에는 재방문할 때마다 선택창 표시
- 승리의 온기를 제외한 나머지 강화 효과를 이전 수치의 50%로 조정

상세 개발 기록과 AI 활용 내역은 `docs/ai-usage-log.md`에서 관리합니다.

남은 개발 일정은 `docs/development-roadmap.md`에서 관리합니다.

## 소스 구조

```text
src/
├─ main.ts                 # Phaser 게임 생성과 실행 진입점
├─ scenes/ArenaScene.ts    # 전투, 방 진행, 선택 UI를 조율하는 메인 장면
├─ data/rooms.ts           # 10개 방 구성과 연결 정보
├─ data/upgrades.ts        # 강화 이름, 설명, 최대 단계 데이터
├─ config/game.ts          # 화면 크기, 쿨다운, 방향 등 공통 상수
├─ types/game.ts           # 적, 방, 강화 공통 TypeScript 타입
└─ style.css               # 페이지와 Canvas 스타일
```
