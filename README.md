# 심연의 화로 (Abyssal Forge)

거대한 지하 제련 던전 `심연의 화로`에 갇힌 마검사가 죽음마다 잿불의 힘을 계승하며 수문장을 쓰러뜨리고 탈출하는 브라우저 기반 2D 탑다운 액션 로그라이트입니다.

공개 테스트: https://jeayeon.github.io/roguelike-game-project/

## 개발 실행

```powershell
npm.cmd install
npm.cmd run dev
```

## 조작

- 시작 화면: `게임 시작` 버튼 또는 `Enter` 입력 후 3초 카운트다운
- 이동: `WASD` 또는 방향키
- 공격: 마우스 왼쪽 버튼 또는 `J` (누르고 있으면 연속 공격)
- 대시: `Space`
- 일시정지: `P` 또는 전투 중 `Esc` — 계속하기와 BGM·효과음 설정 제공
- 사망 후 `이어서 시작`: `R` 또는 버튼 — 재와 화로 영구 강화만 유지하고 일반·상점 강화를 초기화한 뒤 3초 카운트다운 후 첫 방부터 재시작
- 사망 후 `새 게임 시작`: 버튼 — 재와 강화를 포함한 모든 진행을 초기화하고 첫 방부터 재시작

## 현재 프로토타입

- 플레이어 이동, 마우스 조준, 이동 위치를 따라오는 전방 부채꼴 판정과 걸으면서 칼을 휘두르는 4프레임 공격 동작
- 승인된 어두운 판타지 시안을 적용한 플레이어·적 3종·보스 이미지와 4프레임 걷기 동작
- 무적 시간이 있는 대시
- 기본 대시 재사용 대기시간 1초
- 일반 탐색용 어두운 앰비언트 음악과 보스전 전용 전투 음악, 브라우저 오디오 잠금 지연 시 다음 입력에서 자동 재개
- 낮고 넓은 `부웅` 검 바람음, 사람의 `쉿` 소리에 가까운 고주파 `퓨슉` 베임음, 둔탁한 플레이어 피격음과 바람을 가르는 `샤악` 대시음
- 추적자의 저음 남성 신음, 골렘의 벽돌 붕괴음, 원거리 사수의 고음 여성 비명 등 적 종류별 처치음과 방 정리·강화 선택·보스 각성 효과음
- 시작 화면과 일시정지 화면에서 배경음악·효과음 음량을 각각 조절하고 브라우저에 저장하며 주요 전투 효과음과 적 종류별 처치음을 각각 미리 듣기
- 서로 다른 행동을 가진 일반 적 3종: 추격자, 중갑 수호자, 원거리 사수
- 4×4 격자로 상하좌우 연결된 16개 방을 자유롭게 탐색하는 던전 구조
- 방 이동 회복을 제거하고, 처음 정리한 일반 전투방에서 기본 6과 `승리의 온기` 보너스를 합산해 회복
- 강화 선택 화면에서 기본·스킬·실제 회복량을 함께 표시
- 매 회차 위치가 달라지는 회복방·상점방·보스방
- 보스방은 시작 지점과 너무 가까워지지 않도록 심층 후보 방 중에서 무작위 배치
- 출구 색상과 안내 문구로 다음 방 구분: 전투방 청색, 회복방 녹색, 상점방 노란색, 보스방 빨간색
- 3방향 탄막과 높은 체력을 가진 최종 보스 `화로의 수문장`
- 일반 접속 시 시작 화면에서 대기하고 사용자가 시작한 뒤 첫 방 생성
- 보스 체력바, 공격 예고 원과 패턴 안내 문구
- 보스 최대 체력 1200
- 보스방 벽에서 3.2초마다 가로 2줄·세로 3줄의 일정 간격 직선 불덩이 발사
- 벽 불덩이 발사 0.9초 전에 발사 지점·진행 경로·좌우/상하 방향 화살표 표시
- 보스 체력 65%·30%를 기준으로 3방향, 5방향, 전방위 탄막의 3단계 패턴 변화
- 공격 방향선이 실제 발사 방향으로 고정되어 대시 회피 시점을 판단할 수 있음
- 보스 2·3단계 진입 시 각성 문구, 섬광, 흔들림, 1초 무적과 강한 플레이어 넉백
- 원거리 사수의 얼음 화살과 보스의 불덩이 투사체 애니메이션
- 플레이어와 적 피격 점멸, 일반 적의 강화된 피격 넉백
- 플레이어·일반 적·보스 외곽선 필터로 어두운 배경에서 캐릭터 경계 보정
- 각 방의 적 수를 이전 버전보다 약 1.5배 증가
- 모든 적에게 방 경계 충돌을 적용하여 원거리 적이 전투 구역 밖으로 이탈하지 않음
- 적 이미지의 몸체 크기에 맞춘 충돌·공격 피격 반경 적용
- 기본 근접 공격 길이 74px와 캐릭터 이미지 몸체에 맞춘 플레이어 피격 판정
- 어느 방향에서 입장해도 적이 플레이어로부터 최소 210px 떨어진 위치에 생성됨
- 처음 정리한 일반 방마다 무작위 강화 3개 중 하나 선택
- 공격·생존·기동 계열 강화 10종과 최대 3~5단계 중첩
- 대시 재사용 대기시간 강화는 단계당 0.2초 감소하고, 대시·무적 지속시간 강화는 단계당 0.1초 증가
- 화면 왼쪽 상단에서 현재 획득한 강화와 레벨 확인
- 적 처치 시 `재` 획득(추격자 2, 원거리 사수 3, 중갑 수호자 4, 보스 33)
- 무작위 위치의 회복방에서 35% 회복 또는 최대·현재 생명 각 5 증가 중 1회 선택
- 무작위 위치의 상점방에서 구매 카드 3개(회복약 1개·무작위 강화 2개) 중 하나를 선택
- 상점 하단의 별도 버튼 또는 `Esc`/`4`로 거래하지 않고 나가기
- 회복방과 상점방은 실제 사용·구매 후에만 소진되며, 아무것도 선택하지 않으면 재방문 시 다시 표시
- 피격, 회복, 사망 및 재도전
- 이어서 시작 시 `잔불의 제단`에서 대시 계열을 제외한 8종의 영구 강화 중 무작위 3개를 재로 구매
- 영구 강화는 이후 이어지는 모든 회차에 유지되며 `새 게임 시작`에서만 초기화
- `localStorage`에 재·화로 영구 강화·음량 설정을 즉시 저장해 브라우저를 닫아도 이어서 진행
- 기본 생명 50으로 시작
- 회복방은 회복하지 않고 나갈 수 있으며, 실제 회복을 사용하기 전에는 재방문할 때마다 선택창 표시
- 승리의 온기를 제외한 나머지 강화 효과를 이전 수치의 50%로 조정

상세 개발 기록과 AI 활용 내역은 `docs/ai-usage-log.md`에서 관리합니다.

남은 개발 일정은 `docs/development-roadmap.md`에서 관리합니다.

## 소스 구조

```text
src/
├─ main.ts                 # Phaser 게임 생성과 실행 진입점
├─ audio/AdaptiveMusic.ts  # 일반방·보스방 음악과 전투 효과음 실시간 합성
├─ scenes/ArenaScene.ts    # 전투, 방 진행, 선택 UI를 조율하는 메인 장면
├─ data/rooms.ts           # 4×4, 16개 방 구성과 연결 정보
├─ data/upgrades.ts        # 강화 이름, 설명, 최대 단계 데이터
├─ data/permanentUpgrades.ts # 영구 강화 비용과 단계 데이터
├─ data/persistence.ts      # 재·영구 강화·음량 설정의 브라우저 저장
├─ config/game.ts          # 화면 크기, 쿨다운, 방향 등 공통 상수
├─ types/game.ts           # 적, 방, 강화 공통 TypeScript 타입
└─ style.css               # 페이지와 Canvas 스타일

public/assets/characters/  # 플레이어·적·보스 투명 PNG와 걷기 스프라이트 시트
public/assets/projectiles/ # 얼음 화살·불덩이 투사체 스프라이트 시트
```
